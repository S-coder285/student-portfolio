My Projects

Predictive Housing Price Analytics

This project is a predictive analytics application designed to estimate residential property values by leveraging Python, Pandas, NumPy, and Scikit-Learn to build a robust Linear Regression model. It solves the problem of information asymmetry in real estate by identifying core market features like location and square footage, allowing buyers and agents to make fair, data-driven decisions. Using Matplotlib and Seaborn for exploratory data analysis, the system cleans raw datasets and removes the guesswork from property valuation through clear visual trends.

Customer Churn Classification System

Developed inside Jupyter Notebooks, this project features a classification pipeline that analyzes consumer behavior patterns using Python, Pandas, and Scikit-Learn algorithms like Logistic Regression and Random Forest. It directly addresses the critical business problem of customer attrition by evaluating variables such as usage frequency and support history to flag high-risk subscribers. The resulting predictive model provides marketing teams with actionable insights, allowing businesses to launch proactive retention campaigns before customers cancel their services.

Automated Text Sentiment Analyzer

This Natural Language Processing (NLP) tool automates content moderation by utilizing Python and the Natural Language Toolkit (NLTK) to pre-process unstructured text, which is then classified as positive, negative, or neutral using a Scikit-Learn Naïve Bayes model. It solves the challenge of manually monitoring public reputation by transforming product reviews and social media comments into real-time, quantifiable consumer insights. The entire system is deployed via a user-friendly web interface powered by Streamlit, making the AI-driven insights accessible to any business team.
